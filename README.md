# SANGAM

A minimal landing page for **Sangam** that informs users when a scanned product/coupon QR code is invalid or missing the required companion app.

## What It Does

- Greets users scanning legacy or partner QR codes (Eurogrip, Valvoline, Roots).
- Displays a clean error modal (`QR-SANGAM-404`) explaining the scan cannot be completed.
- Provides direct store contact details (phone, email, address) for dealer assistance.

## Deployment

Static HTML/CSS/JS, visit [here](https://sangamtyres.github.io/qr_redirect/) to visit the deployed site.

Or you can host it locally, by cloning the repo and running the command below.

```bash
cd qr_redirect
open index.html
```
